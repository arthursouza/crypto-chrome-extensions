# FOMO to GMGN & BasedBot Token Linker

A lightweight Chrome Extension for [fomo.family](https://fomo.family) that injects compact, one-click trading and analytics buttons for **GMGN** and **BasedBot** across token lists and token detail pages.

## Features

- ⚡ **Ultra-Compact Buttons**: Specially sized (18px height) to fit smoothly into token lists, tables, and header rows without cluttering the UI.
- 📊 **GMGN Integration**: Direct trading & analytics links using token referral path format (`https://gmgn.ai/{chain}/token/yjpf6bOc_{address}`).
- 🤖 **BasedBot Integration**: Direct token trading links (`https://basedbot.app/r/lotuzx/token/{chain}/{address}`) pre-configured with the default referral `/r/lotuzx`.
- 🌐 **Multi-Chain Support**: Automatic chain detection and routing for Solana, Robinhood, Base, Ethereum, BSC, Arbitrum, Monad, and more.
- ⚙️ **Customizable Settings**:
  - Toggle GMGN and BasedBot buttons independently.
  - Choose display locations: Token Lists (`/tokens`) and Token Detail Pages.
  - Optional Floating Quick Buttons.
  - Toggle open in new tab vs current tab.

## Installation

1. Open Google Chrome and go to `chrome://extensions/`.
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked** and select the `fomo-click-to-gmgn` directory.
4. Visit [fomo.family](https://fomo.family/tokens) to see the buttons in action!
